- The project is maintained on parallel branches, one per Spring Boot minor line (`3.5`, `4.0`, and `main` for the latest). Each release version tracks the Spring Boot version it builds against, e.g. `4.0.7.1` targets Spring Boot 4.0.7 and `3.5.16.1` targets Spring Boot 3.5.16.
- **4.0.8.2** The generated schema no longer depends on the JDK that runs the application. *Behaviour change:* `java.util.Locale` and `java.nio.charset.Charset` are now plain strings with a short fixed list of `examples`, not an `enum` of every value the running JDK knows (that list differed per JDK and rejected valid values such as `en-US` or `utf-8`). Static and compiler-generated fields are skipped, types of the Java runtime (`java.*`, `jdk.*` modules) are no longer expanded field by field, enum values keep their declaration order and extracted `$defs` are sorted by name. To get an enumeration back, map the type in `json-config-schema.json-schema-properties-map`.
